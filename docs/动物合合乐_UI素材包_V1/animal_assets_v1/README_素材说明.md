# 动物合合乐 UI 素材包 V1

## 本批内容

以最新暖木色 UI 为造型参考，交付12张独立素材：8张动物、3张UI、1张无字场景背景。另附原UI参考图、资源清单CSV、尺寸与透明信息JSON、可离线打开的HTML拼装预览。

本批是生成式重绘与背景补绘（generated-edit），不是原图分层文件或像素级裁切。图片存在合理造型漂移。没有提供序列帧、骨骼、音效或Cocos工程。

## 范围与缺口

本批覆盖参考图中可见的动物阶段，不等于完整14种动物库。四层合成的老虎仍需s3生动姿态；大象仍需s2完整上色和s3生动姿态。猫的完整玩法链和其他物种未在本批制作。不得为了适配已有素材而擅自减少PRD合成层数。

参考图中顶部木座、爪印装饰不作为独立精确素材交付。示例预览使用通用无字面板替代目标数量底板，静态环境合入背景。标题字体、数字、阶段圆牌、完成勾选、拖动虚线、轻微阴影和吸附高亮由程序绘制。暂不提供按钮按下图；按下时缩放/变色即可。

## 图片与透明检查

- 8张动物与暂停按钮：1254×1254 RGBA。
- 无字面板、提示按钮：2172×724 RGBA。
- 场景底图：941×1671 RGB，竖屏。
- 所有11张透明素材已读取并检测到alpha=0像素，具体统计见manifest.json。
- 已查看生成结果，检查动物完整外形、无文字角标、灰色与彩色差异，并对蓝耳朵大象的明显外围灰雾进行了生成式修复。
- 透明图仍可能有低alpha散点、少量柔边；alpha存在不代表所有边缘都已达到上线品质。未完成浅色/深色底下的浏览器渲染检查。
- 当前灰色动物仍有少量粉色耳内、腮红及眼部色彩，主体保持中灰色；不是全图纯灰度转换。

## Cocos接入建议

1. 以独立Sprite加载PNG，保持原图比例，不要把大象拉瘦或把兔子压扁。
2. 初始可用Canvas 941×1671或等比例设计尺寸。长屏需单独处理上下安全区；本背景为固定比例，不能承诺直接适配所有屏幕。
3. 根节点锚点可先设(0.5,0.5)。同阶段多个实例共用SpriteFrame。
4. 建议主体显示宽约140—190设计像素，具体依物种与界面密度调整；不要把1254像素当作屏幕尺寸。
5. manifest记录原始alpha包围盒和alpha>=128的可见包围盒，可用后者计算视觉中心与可见高度。原PNG未紧裁，crop_offset为(0,0)。
6. 每个物种的不同阶段存在姿态与透明留白差异，应按可见主体包围盒校准缩放和落脚点，不能仅因画布相同就认为动画无跳位。
7. 家园目标可复用灰色阶段图并缩小；目标数量和已入住进度用Label。
8. 阶段圆牌作为动物节点的独立子节点，命中与拖动归属动物本体。
9. 无字奶油底板原图偏长：标题可等比例缩放，短计数面板建议设置SLICED并保护左右圆角。九宫格边距尚未实测，不提供伪造的精确边距。
10. ui_hint已有灯泡，文字显示在右侧空白区域；触摸热区应围绕可见按钮主体，不包含大块透明留白。
11. 本批资源较大，正式发布前应做尺寸缩减和纹理压缩评估；源图保留用于后续修订。

## 拼装预览

解压整个文件夹后，双击“拼装预览.html”。PNG必须与HTML放在同一目录。页面上半部分按独立图片节点构建竖屏布局，下半部分为资源目录，可切换深浅底色观察边缘。

预览不使用UI_reference.png作为背景掩盖资源缺口。它使用background_clean.png和独立动物/UI PNG，文本与圆牌为HTML/CSS绘制。它是静态布局示意，不实现拖动合成游戏。

当前环境的Playwright缺少浏览器可执行文件，尝试启动失败，因此HTML已经生成，但尚未实际截图或浏览器验收。没有提供伪造的“已通过”截图。未导入Cocos、未跑手机实机、未验证帧率与触控。

## 后续美术重点

- 参考UI中老虎本就接近橘猫，新素材仍有相似性。后续建议强化老虎的圆耳、宽脸与专属条纹，再投入包含猫和老虎的同屏找物关卡。
- 老虎各阶段耳型、兔子各阶段姿态有变化，需要后续统一，避免合成时产生明显形变跳跃。
- 本批适合素材确认与首轮联调，不标为“完整生产验收通过”。

## 制作记录

使用内置图像生成工具；以用户确认的暖木UI作为身份与画风输入。动物提示要求独立主体、真实透明背景、移除数字和高亮；背景提示要求去除动物及文字并补齐遮挡；UI提示要求无字底板与可复用按钮。源UI保留为UI_reference.png。
